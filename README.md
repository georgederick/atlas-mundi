🌎 Atlas Mundial

O **Atlas Mundial** é um projeto web interativo que permite explorar os continentes e conhecer os países do mundo por meio de um mapa-múndi.

Ao selecionar um continente, o usuário pode visualizar seus países e acessar informações individuais, como capital, população, área territorial, idiomas, moeda, história, cultura e curiosidades.

Funcionalidades
- Mapa-múndi interativo.
- Navegação entre continentes.
- Visualização dos países por continente.
- Informações geográficas e demográficas.
- Bandeiras dos países.
- Pesquisa de países.
- Curiosidades históricas e culturais.
- Interface responsiva.

Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

Objetivo
Criar uma plataforma de exploração geográfica que reúna informações sobre os países do mundo de maneira visual, intuitiva e acessível, aplicando conhecimentos de desenvolvimento Front-End e manipulação de dados com JavaScript.
